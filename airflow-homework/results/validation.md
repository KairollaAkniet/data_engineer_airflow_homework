# Тексеру нәтижелері

2026 жылғы 5 қазанда WSL Ubuntu ортасында тексерілді.
Python 3.10.22, Apache Airflow 2.8.0, Spark provider 4.1.5,
PySpark 3.4.0 және Java 11.0.32.1 пайдаланылды.

27 автотесттің бәрі өтті. Екі DAG те нақты Airflow `DAG.test()`
іске қосылуында SUCCESS күйімен аяқталды.

Негізгі DAG-те notify_success орындалды, notify_warning SKIPPED болды,
end SUCCESS күйіне өтті. TaskFlow DAG-тегі үш тапсырма да SUCCESS болды.
XCom нақты Airflow мәліметтер қорында қолданылды; DagBag және операторлар
нақты Airflow кітапханасынан жүктелді.

Бастапқы дерек: 9 980 жол. Тазаланған дерек: 9 975 жол.
5 жолдың міндетті өрісі бос болғандықтан жойылды. 13 сала бар.
Acting саласында 9 320 жол бар.

Тесттер DAG конфигурациясын, оператор түрлерін, толық тәуелділіктерді,
TaskFlow XCom байланысын, SLA, retry, doc_md, CSV тексерулерін,
100 жол шекарасындағы тармақты, хабарламаларды, Spark нәтижелерін,
үш SQL есепті, партициялап жазуды және мәтіндік есепті қамтиды.
SQL және орташа танымалдылық бастапқы CSV бойынша тәуелсіз Python
есептеуімен салыстырылды.

Python файлдарының синтаксисі тексерілді, COMMENT токендерінің саны — 0.
Кодта docstring жоқ. SLA және retry түсіндірмелері README-де берілген.
Құжат талап ететін doc_md Airflow интерфейсіне арналған мәтін ретінде сақталды.

`tests.txt` — автотесттердің шығысы.
`pipeline.log` — екі нақты DAG іске қосылуының журналы.
`dag_runs.txt` — екі іске қосылудың сәтті аяқталу белгісі.
`../output/final_report.txt` — жасалған есеп.
`../output/` — Parquet нәтижелері.

GitHub Actions файлы дайын. Репозиторийге жариялау және сыртқы GitHub CI
іске қосылуы жасалған жоқ. Жоспарланған SLA мониторингі қолмен жасалған
осы DAG тексерісінен бөлек жұмыс істейді.
